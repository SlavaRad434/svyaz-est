# СвязьЕсть — учебный прототип

Мобильное веб-приложение с картой качества связи, автоматическим сбором замеров
и объяснимой оценкой зон. **Текущий режим — демо**: данные не покидают браузер,
наблюдения не являются реальными замерами.

## Запуск

Требуется Node.js ≥ 20. Последовательность команд:

```sh
npm install
npm run check   # lint + typecheck + тесты + сборка
npm run dev     # приложение на http://localhost:5173
```

### Ключ Яндекс Карт (необязательно для демо)

Без ключа приложение работает: карта показывает явное состояние ошибки загрузки
с повтором, остальной сценарий (фильтры, карточка, тест) доступен. Для отображения
карты скопируйте `.env.example` в `apps/web/.env.local`, укажите `VITE_YMAPS_API_KEY`
и перезапустите dev-сервер. Ключ: https://developer.tech.yandex.ru/

## Структура

```text
apps/web/              React + Vite + Mantine: экраны, карта, демо-адаптер
packages/contracts/    DTO, zod-схемы, коды ошибок, интерфейс DataGateway
packages/domain/       чистые функции: сетка 250×250 м, evaluateCell, методика
docs/                  архитектура, контракты, wireframe-ы, план реализации
```

`packages/domain` не зависит от React, NestJS и БД; карта и карточка используют
один и тот же расчёт `evaluateCell`. Демо-адаптер и будущий HTTP-адаптер
реализуют один контракт `DataGateway`.

## Демо-допущения (зафиксированы для прототипа)

Эти параметры открыты в документации как «требуют решения команды»; для демо
зафиксированы в `packages/domain/src/demo-grid.ts`:

- Пилот: центр Москвы, граница около 3×2 км (`gridVersion: demo-msk-v1`).
- Проекция: локальная равнопромежуточная вокруг центра пилота с поправкой
  cos(55.7558°); погрешность размера квадрата 250 м на местности < 1%.
- Часовой пояс пилота: UTC+3 (без сезонного перехода) — влияет на границы
  суток при дедупликации вкладов автора.
- Методика `2-guest-draft`: окно 30 дней, полураспад веса 14 дней, минимум
  5 замеров из разных сессий за 2 даты, зелёный ≥ 80% прошедших профиль,
  жёлтый ≥ 50%. Параметры — гипотезы до полевой калибровки.

Демо-наборы привязаны к ячейкам вдоль «главной улицы» пилота и покрывают
сценарии из [плана](docs/implementation-plan.md) §5: пустая ячейка, один замер,
зелёная/жёлтая/красная зоны, повторы автора, старые и скрытые записи, только
события ошибок, исключаемые метаданные, гостевые замеры.

## Команды

| Команда | Что делает |
|---|---|
| `npm run dev` | Dev-сервер приложения |
| `npm run check` | Lint + typecheck + тесты + сборка |
| `npm test` | Тесты контрактов и ядра оценки |
| `npm run build` | Сборка всех workspace |
| `npm run lint` / `npm run typecheck` | Проверки по отдельности |
