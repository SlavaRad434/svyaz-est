# Предварительные wireframe-ы экранных форм

Редакция 2 от 25 ноября 2026 года. **Статус: подготовлено для обсуждения, не согласовано командой.**

Правки редакции 2: подложка переведена с Яндекс Карт на OpenStreetMap (Leaflet) — согласовано 15.11.2026; с экрана «Мои записи» (лист 10) убраны события ошибок — просмотр автоматически сохранённых событий исключён из требований, событие сохраняется и доставляется в фоне без отдельного экрана.

Откройте [галерею экранов](index.html) в браузере. Она работает локально без установки зависимостей и без интернета. В галерее кнопки со ссылками переводят к другому листу, не выполняя реальные операции. SVG-файлы можно открыть отдельно, приложить к отчёту или использовать как основу для обсуждения. Для отдельных SVG навигация между листами не предусмотрена.

Источники: [архитектура](../architecture.md), [контракты](../interfaces.md), [требования](../../svyaz-est-analysis.md). Все дополнительные подписи интерфейса — предлагаемый текст для согласования. Демонстрационные значения не являются реальными замерами. Макеты показывают структуру и приоритет действий; окончательные цвета, иконки и визуальный стиль ещё не утверждены.

## Правила компоновки и навигации

- Мобильная форма — 360×760 CSS px; содержимое длинных форм прокручивается вертикально. Десктопная композиция — 1280×900. В галерее листы могут уменьшаться для просмотра; это не проверка адаптивности будущего приложения.
- Карта остаётся основным экраном. На смартфоне фильтры открываются панелью, карточка — снизу. В десктопной версии фильтры видны постоянно слева. Кнопка «Запустить тест» доступна гостю.
- Возврат с теста, методики или входа восстанавливает прежние границы карты, фильтры и выбранную ячейку. «Назад» на методике возвращает к месту открытия; ссылка в статической галерее показывает один пример такого возврата.
- Вход не появляется обязательным шагом перед измерением. Гостевые данные не присваиваются аккаунту после входа. История аккаунта и локальная очередь — разные экраны: очередь доступна гостю, серверная история аккаунта — участнику.
- Данные замера, место, оператор и условия не редактируются. Неизвестные сведения остаются неизвестными. Фильтры просмотра не меняют собранные метаданные.
- «Повторить тест» создаёт новую попытку; «Повторить отправку» доставляет прежний результат. Отмена измерения не создаёт событие сетевой ошибки.
- Действия модерации скрыты для гостя и участника; в приложении дополнительно проверяются сервером. «Скрыть запись» недоступно до выбора причины. Для уже скрытой записи используется «Восстановить» с тем же обязательным выбором причины.
- Диалог удаления возвращает к экрану вызова. Для аккаунта заголовок «Удалить аккаунт?», текст «Аккаунт и связанные записи будут удалены. Оценки зон будут пересчитаны», кнопки «Отмена» и «Удалить аккаунт». Для очереди последствия относятся только к неотправленной записи. Кнопки блокируются на время запроса, двойное нажатие не создаёт повторную операцию.
- В фильтрах доступны два профиля: «Базовые задачи» и «Видеозвонок». Лист методики показывает второй; для первого блок порогов заменяется на download ≥1 Мбит/с, upload ≥0,5 Мбит/с, RTT ≤300 мс. Границы цвета общие. При сбросе восстанавливается согласованный набор начальных фильтров; он ещё требует решения команды.
- Во всех состояниях текст объясняет статус. Буквы З/Ж/К/Н/Д в серой схеме карты обозначают будущие цвета и текстовую легенду. Красный не означает доказанное отсутствие сети. Число разных авторов гостевых записей не заявляется.
- На листе подготовки вместо выбранного числа трафика стоит обозначение конфигурации. В реализации до старта обязательно показывается конкретный лимит в МБ; его значение нужно согласовать, а не оставить техническую заглушку.

## Состояния форм

Варианты в серых блоках на листах 04, 09, 17–19 показаны рядом для ревью. В продукте они отображаются по условию, не одновременно. «Недостаточно данных» относится к оценке связи; для списков используется пустое состояние, для входа и действий — ожидание/успех/ошибка.

| Форма | Ожидание | Успех | Нет данных / ограничение | Ошибка / восстановление |
|---|---|---|---|---|
| Карта и карточка | Лист 17: загрузка, без преждевременного цвета | 01, 03 | 17: нет замеров и недостаточная выборка различаются | 17: ошибка API/карты и повтор; прежняя оценка не маркируется свежей |
| Фильтры | Загрузка справочника, применение с блокировкой повторного нажатия | 02 → 01 с едиными фильтрами | Пустая группа → 17, значения unknown доступны отдельно | Сохранить выбор, предложить повтор загрузки |
| Вход | 04: ожидание провайдера | Возврат к исходному экрану, без присвоения гостевых записей | Продолжить гостем | 04: повтор или закрытие |
| Измерение | 06: этап, время, трафик и отмена | 07, вариант учтённого результата на 18 | 18: локальный результат без геолокации | 08: событие ошибки; отмена отдельно на 18 |
| Очередь | 08, 09: ожидание связи/отправка | Квитанция и снятие с отправки | Пустая очередь: «Нет ожидающих отправки записей» | 09, 18: срок, отказ хранилища, потеря ответа; заблокированная доставка объясняется без бесконечного повтора |
| История | Общая загрузка списка на 19 | 10 | 19: «У вас пока нет записей» | 19: ошибка загрузки с повтором, сохранение списка при ошибке удаления |
| Аккаунт и удаление | 12: подтверждение; затем ожидание запроса | 19: удалено; для аккаунта — запрос принят с пояснением срока | Чужая запись недоступна; форма не предлагает её удалить | 19: ошибка, диалог остаётся, повтор доступен |
| Модерация и журнал | 19: общий шаблон загрузки списка | 13–15 | «Нет записей по выбранным фильтрам» | Нет роли — отказ доступа; ошибка решения не меняет статус записи, повтор доступен |
| Методика | Общий шаблон загрузки содержимого | 16 | Неизвестная версия не заменяется актуальной молча | «Не удалось загрузить методику», повтор и возврат |

## Соответствие будущему UI kit

Существующего UI kit в репозитории нет. В архитектуре Mantine предложен, но ещё не утверждён. SVG не подключают библиотеку и не являются реализацией её API. На этапе разработки нужно проверить доступные компоненты и их актуальные свойства.

| Элемент wireframe | Предлагаемая основа Mantine |
|---|---|
| Основное/вторичное действие | Button |
| Выбор оператора, сети, условий и причины | Select |
| Панель фильтров и мобильная карточка | Drawer / согласованная нижняя панель |
| Подтверждение удаления | Modal |
| Прогресс теста | Progress, Loader |
| Ошибка и статус доставки | Alert, текстовая подпись |
| Метрики и группы действий | Stack, Group, Text, Divider |
| Карта и полигоны | Яндекс Карты v3, собственная легенда |

Размеры действий в макетах не менее 44 px по высоте. Для реализации отдельно проверяются клавиатура, видимый фокус, возврат фокуса после диалога, объявление статусов экранному диктору и отсутствие горизонтального скролла. Статический SVG не доказывает выполнение этих требований.

Для обсуждения пройти четыре сценария: выбрать место для видеозвонка; гостем получить результат; пережить сбой и повторить отправку; администратором скрыть и восстановить запись. ## Воспроизведение

Исходник макетов — `generate.py` (стандартная библиотека Python, без зависимостей). Пересборка: `python3 docs/wireframes/generate.py`. Генератор создаёт SVG и HTML-галерею, не код приложения. Изменения вносятся в генератор, чтобы отдельные листы и галерея оставались синхронны.
